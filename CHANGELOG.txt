# Change Log
[ToLaserBlade (for Better than Adventure!)](https://modrinth.com/mod/tolaserblade/versions?s=true&g=b1.7.3).
[Source](https://github.com/Iunius118/ToLaserBlade-BTA).

## [Unreleased]

## [1.5.0+8.0.1]
### Added
- Add a trail effect to the laser blade held by the local player when swinging.
- Add `enable_laser_blade_trail` option to `Client` category in the config file.
  If true, display a trail effect when the local player swings a laser blade.

### Changed
- Use JSON file instead of RecipeBuilder to register recipes.

## [1.4.0+8.0.1]
### Added
- Add `use_3d_laser_blade_icons` option to `Client` category in the config file.
  If true, use 3D models for laser blades on the head, on the ground, and in GUIs; otherwise, use 2D textures.

### Changed
- Require HalpLibe 6.2.0+8.0.1.
- Use 3D models for laser blades on the head, on the ground, and in GUIs.
  The previous appearance can be restored in the config file.

### Fixed
- Fix mod initialization and various registrations.

## [1.3.0+8.0.1]
### Added
- Add `tolaserblade/laser_blade` shader for laser blade.

### Changed
- Port to BTA 8.0.1.
- Require Better than Adventure! Fabric 8.0.1 and HalpLibe 6.1.3+8.0.

### Fixed
- Change item description of laser blade.

## [1.2.0]
### Changed
- Port to BTA 7.3_04.
- Require Better than Adventure! Babric 7.3_04 and HalpLibe 5.2.4.
- Change color of orange laser blade.
- Add all color variations of laser blade to creative inventory.

## [1.1.0]
### Changed
- Port to BTA 7.1_01.
- Require Better than Adventure! Babric 7.1_01 and HalpLibe 3.5.4.

## [1.0.0-beta.1]
### Added
- 15 different colors to laser blade. The color of the laser blade is determined by the color of the lamp in the crafting material.

### Changed
- Laser blade recipes now require steel ingots and lamp.

### Fixed
- Size of rendered laser blade.
- Rendering of laser blade in preview area in player's inventory.

## [1.0.0-alpha.1]
### Changed
- Require Better than Adventure! Babric 1.7.7.0_02 and HalpLibe 2.7.0+.

### Added
- Laser blade item and recipe.
